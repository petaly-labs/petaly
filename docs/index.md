# Petaly Documentation

Welcome to the Petaly documentation. Petaly is an ETL (Extract, Transform, Load) tool that helps you move and transform data between various sources and destinations.

## Quick Start

1. **Installation**
   ```bash
   pip install petaly
   ```

2. **Initialization**
   ```bash
   petaly init --workspace
   ```

3. **Configuration**
   - Edit `petaly.ini` to set up your workspace
   - Configure your data sources and destinations

4. **Usage**
   - CLI Mode: Use command-line interface for traditional ETL
   - Agent Mode: Use natural language for AI-powered ETL [EXPERIMENTAL]

## Features

- **Multiple Data Sources**: Support for databases, files, and cloud storage
- **Flexible Transformations**: Data type conversion, filtering, and aggregation
- **AI Integration**: Natural language interface for ETL operations
- **Cloud Ready**: Support for major cloud platforms
- **Extensible**: Custom connectors and transformations

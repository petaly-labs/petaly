## Getting Started

To get started with Petaly, follow these steps:

1. Install Petaly using pip:
   ```bash
   pip install petaly
   ```

2. Initialize your workspace:
   ```bash
   petaly init --workspace
   ```

3. Configure your `petaly.ini` file with the required settings

4. Choose a tutorial based on your needs:
   - For AI-powered ETL operations, see the [AI Agent Mode Guide](ai_agent_mode.md)
   - For traditional pipeline configuration, see [Pipeline Examples](pipeline_examples.md)
